# 13. Limitations — what this system cannot claim

Written so that a reviewer finds every weakness already admitted rather than
discovering it. Ordered by how much it would change a conclusion.

## 13.1 The ablation gap on CDVQA

**We never ran the base model on CDVQA.** The base was scored only on our own
SpaceNet 7 benchmark (AA 0.3194). So we can say the adapter is level with the
published fine-tuned result for its backbone, but we cannot state the delta over
our *own* zero-shot baseline. One eval run closes it.

This is a gap in the ablation table, not a threat to the headline. An earlier
draft of this document claimed it might be — on a misreading of the cited
figure **67.86** as a zero-shot score. It is not: the source paper reports a
**size sweep of the same fine-tuned LoRA method** (2B 68.59, 4B 67.86, 8B 66.94)
and states that performance does not scale monotonically with model size. 67.86
is the published *fine-tuned* score for Qwen3-VL-4B — our exact backbone — and
our 68.0 is level with it.

## 13.2 Benchmark comparability

**Official scorers were never wrapped.** RSVQA, VRSBench and CDVQA are scored
with the in-repo comparator. Valid for run-to-run comparison; **not quotable as a
benchmark result**. CDVQA ships no evaluation code at all, so there is nothing to
defer to there.

**CDVQA Val is not Test1.** Published comparisons (55.3% baseline, 68.6% SOTA)
are Test1. Ours is Val. Both Test splits are staged and were never scored.

**Our BEN MCQ set is not the paper's.** Generated by our pipeline, with Location,
Season and Climate dropped — the subtypes their table shows are Qwen's
*strongest*. Our set is **harder**; the comparable zero-shot baseline is 35.72,
not 37.55.

**The dual-character licence position** holds only while evaluation stays
academic. Quote VRSBench or CDVQA in a procurement deck and the academic-only
sources no longer back the claim.

## 13.3 The domain gap is open and unclosable with public data

The graded set is **Cartosat-2S optical and RISAT SAR**. Every training source is
Western. This is mitigated by scale conditioning and measured transfer, not
closed. The yardstick is the RSVQA paper's own **5.6-point** test1→test2 drop;
we have no equivalent measurement against Indian sensors because none exist in
our data.

## 13.4 Capabilities that are weaker than the headline suggests

**Counting.** RSVQA-LR `count` is **56.2%** and is the sole reason the LR gate
misses 88. Vision contribution **2.9 points** — largely answered from question
phrasing. The fix is known (bucket the training manifest so the model emits
ranges directly) and was not run.

**`smallest_change`** at 29.3%, below the 32–37% band every published model
occupies.

**Captioning** loses to fine-tuned baselines by ~12 ROUGE-L and clears its
wrong-image floor by **0.008**. On this benchmark ROUGE-L largely measures
register, not sight. Removing the GoogleEarth opener — a deliberate honesty
decision — costs measurable ROUGE-L.

**Grounding is single-box.** 62.7% was measured where each item has exactly one
ground-truth box. **58% of VRSBench targets are non-unique**, and non-unique is
the weak slice (55.4% vs 64.7%). A multi-box answer may help there; the metric
would have to change to precision/recall or mAP, so the headline would not
transfer.

**Grounding has no abstention in the measured number.** VRSBench only asks about
objects that are present. The model does abstain correctly when asked for
something absent, but that behaviour is not covered by 62.7%.

## 13.5 Data quality carried into results

**reBEN's S2 band order is unresolved, and deliberately so.** Neither candidate
order fits reBEN's published per-band statistics (ratio CV 0.408 vs 0.331, with
one channel a wild outlier under the better-fitting order), and the optical model
is at **chance at every order**, so the one experiment that could decide it
carries no signal. No band map was written: a plausible-looking NDVI from the
wrong channel is worse than no NDVI, because nothing downstream can tell.

Consequence: on reBEN cross-modal pairs the optical opinion comes from
`texture_seg` (surface roughness), not a spectral index. A low IoU against radar
backscatter is *expected*, and D1's rule table — written for spectral-vs-radar —
correctly finds no rule and reports `unclassified`.

**Archive integrity.** 42.3% of files in one staged source were unreadable before
re-extraction; 55 pairs remain permanently rejected and are excluded from every
manifest.

**No real Cartosat/RISAT-shaped cross-modal source.** SpaceNet 6 is the right
answer — 0.5 m Capella X-band co-registered with Maxar optical — and only its
optical half is staged. `SAR-Intensity` is a 41 GB fetch that was never made.

## 13.6 Serving

**No answer contract at serving time.** The benchmark scores
`format_answer(raw, contract)`; the product shows the raw generation. Serving
cannot infer a benchmark name from free text. For well-formed questions this is
invisible (IF 100%); for malformed ones an out-of-vocabulary answer can reach the
screen.

**Confidence is a heuristic, not a probability.** `confidence_basis: "heuristic"`
over agreement IoU, threshold-fallback fraction, router path and warning count.
**No calibrator is fitted.** It is an ordering.

**In-memory state.** Scenes, bundles and queries live in process memory;
`max_containers=1`, and a 5-minute idle scaledown loses them.

**Cold start ~45 s** for the first query per container.

## 13.7 The gallery is a curated sample

The 200-item testing corpus contains rows the system answers **correctly**, drawn
from pools where it does not answer everything correctly. It demonstrates
capability; it does not measure accuracy. The page states the real split
accuracies beside it, and the honest read on end-to-end accuracy is the pass rate
on *unfiltered* replacement rows — around two thirds.

## 13.8 Verification gaps that remain

- `verify_routes.py` uses **stub adapters** — it proves plumbing, nothing about
  answer quality.
- 100 gallery items (`change_vqa`, `rs_vqa`) were verified against a build four
  deploys old. Their routing is unchanged and their code path untouched, but they
  were not re-run.
- The **shuffle control has never been run on the CDVQA adapter** — the decisive
  check for how much of 68.0% is vision.

## 13.9 Things believed but not demonstrated

- that fine-tuning grounding on our corpus would *not* beat 62.7% (expected,
  given 9% class coverage — but an expectation);
- that captioning fine-tuning would make the model worse (argued from a 16-word
  median against a 47-word target — not tested);
- that the system transfers to Cartosat/RISAT at all.
